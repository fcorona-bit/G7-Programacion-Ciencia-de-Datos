# G7 - Programación para la Ciencia de Datos

## Descripción
Repositorio académico del curso Programación para la Ciencia de Datos, correspondiente al Magíster en Ciencia de Datos e Inteligencia Artificial de la Universidad Andrés Bello.

## Objetivo
Desarrollar habilidades de programación para procesar, analizar y transformar datos mediante actividades prácticas.

## Contenido
Este repositorio almacenará los ejercicios, actividades y entregas académicas del curso.

## Herramientas
- Python
- Git
- GitHub
- Jupyter Notebooks

## Estado
Repositorio en preparación.
